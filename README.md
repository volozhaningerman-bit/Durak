# Durak RPG

Telegram Mini App: классический и RPG-режимы игры «Дурак» для 2–6 игроков.

## Режимы

### Классический
Настраиваемые правила:
- 2–6 игроков
- подкидной / переводной
- кто может подкидывать: все / крайние
- дополнительные параметры будут добавляться через единый объект настроек комнаты

### RPG
Всегда подкидной + переводной. Игрокам случайно выдаются уникальные классы.

1. **Козырник** — после обычной раздачи выбирает ровно одну козырную масть. Сервер находит карту этой масти в оставшейся колоде, переносит её вниз и делает открытой козырной картой.
2. **Переводчик** — до 2 раз за матч может перевести атаку любой своей картой, даже если достоинство не совпадает.
3. **Пятёрочник** — на него можно положить максимум 5 атакующих карт; после хода он добирает из колоды только до 5 карт вместо 6.
4. **Подкидчик** — при каждом подкидывании получает первый приоритет. После него подкидывает исходный атакующий, затем остальные допустимые игроки.
5. **Реверс** — может перевести атаку в обратном направлении. Такой перевод также разворачивает глобальное направление партии до следующего реверса.
6. **Джокер** — после обычной раздачи 6 карт получает дополнительную 7-ю карту-джокер. Джокер может побить любую карту и после использования уходит как обычная сыгранная карта.

## Архитектура

- `apps/web` — Telegram Mini App, React + TypeScript
- `apps/server` — authoritative game server, Node.js + WebSocket
- `packages/game-core` — чистая игровая логика и тесты
- PostgreSQL — профили, прогресс, история матчей, инвентарь
- WebSocket — realtime-синхронизация 2–6 игроков
- Telegram initData — авторизация с серверной проверкой

## Принципы

- Сервер является единственным источником истины.
- Клиент не решает, допустим ли ход.
- RPG-классы реализуются отдельными модификаторами правил.
- Игровая логика отделена от Telegram и UI, чтобы её можно было тестировать без запуска приложения.
- Темы интерфейса: classic / casino / dark / rus-fantasy.

## Монетизация

Архитектура предусматривает Telegram Stars:
- косметика;
- эмоции/насмешки и броски предметов;
- расходники/способности комнаты через feature flags.

Игровые расходники будут отделены от рейтинговых правил, чтобы их можно было независимо включать/выключать для разных очередей.

## Статус

Базовая архитектура и игровое ядро в разработке. Основные RPG-классы и их ограничения зафиксированы тестами.
